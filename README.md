# Roblox UGC Advanced Analytics Bot

A full-catalog scanner that discovers, enriches, and analyzes UGC items
using both **titles AND descriptions** to find viral keywords.

## Commands
- `!scan_status` – Shows discovered IDs, analyzed items, and items with descriptions
- `!trends` – Top words across titles + descriptions of best-selling items
- `!analyze <keyword>` – Deep keyword analysis (titles + descriptions)
- `!desc_analyze <keyword>` – Finds hidden keyword goldmines in descriptions only
